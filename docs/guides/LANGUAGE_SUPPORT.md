# 语言辅助

角色卡继续决定人格、语气和表达方式。此集成只从 [MX3a48c5/dsh-fish-tone](https://github.com/MX3a48c5/dsh-fish-tone) 保留只读草稿检查及静态词典，不安装它的全局插件、风格设置、润色器或独立查梗工具。

## 草稿检查

`text.judge` 通过现有内容服务提供。输入为 `{ "text": "需要检查的草稿" }`，最多 6000 字符；输出保留原文并给出有限的句式提示，不生成替代回复，也不是 AI 文本鉴定。仅在草稿明显生硬时按需使用，不必每条回复调用或照单改写。角色卡与当前对话语境仍决定最终回复。

沿用内容服务的会话权限和审批：未授权默认拒绝，不读取群历史、角色卡或记忆，不联网、不写状态。安装脚本只对现有 QQ 白名单补充缺失的精确会话授权；保留已有拒绝、审批和停用设置。

## 黑话查询补充

二代仿真唤醒时，桥接会根据本轮实际提供的来信、工作记忆原文和消息快照，自动匹配已确认黑话与静态梗库中的词条或别名，不依赖模型先调用查询工具。每轮默认最多8条，结果总预算2000字符；只扫描最多24段、合计12000字符的已展示文本，最新来信优先。单字和英文缩写检查词边界，避免把普通词中的片段误当成梗。同一处已有确认释义时，不附加通用释义。没有匹配就不注入。

自动检索独立于 `context.strategy`，二代唤醒不再同时附带旧的通用黑话列表。它遵循 `slang.enabled`、`socialV2.tools.slangQuery` 和下述词典参考开关；读取工具未提供的消息不参与检索。过程只读，不联网、不学习或写入词库。模型对仍不理解的词应主动查询，不需要群友先说“查一下”；已提供的同一释义无需重复查。

继续使用原有 `qq_slang_query` 或 `qq_context_query(kind="slang")`。先检索已确认黑话；未命中时才查静态词典，返回 `source: "static-reference"`、`confirmed: false`，注明未经本群确认。已有群内释义不会被通用释义替换，候选词也不会因此转为已确认。上游未考据的释义会明确标为未知，查询不会自动写入黑话库。

在控制台「黑话词库」的原有参数中，可关闭「已确认黑话未命中时，补充通用词典参考」。配置项为 `slang.referenceFallback`，默认开启；原有 `slang.enabled` 总开关仍生效。没有查询词时不会随机注入词典内容。

## 查看和编辑通用梗库

进入控制台「黑话词库」，在「通用梗库」中按梗词、别名、释义、用法或来源搜索，可按网络梗/句式、启用/停用/本地修改筛选，每页50条。点击「编辑」可修改名称、别名、释义、用法、参考来源、考据状态与启用状态，也可「新增梗」。内置词条保留原始来源，可「恢复内置原版」；不想使用时取消启用，自建词条可删除。

保存成功后立即影响 `qq_slang_query`、`qq_context_query(kind="slang")` 和后续自动检索，无须重启。停用项不参与检索；未考据项仍明确表示未知。通用梗库的本地修改依然是参考资料，不会自动变成已确认黑话；群内特定用法请在原有黑话管理中确认，它仍优先于通用解释。

修改保存在忽略提交的 `state/slang-reference.json`，重启后恢复；备份运行数据时应包含此文件。上游 `memes.json` 与 `constructions.json` 不会被管理操作改写。管理员页面采用版本检查，其他窗口已保存时会拒绝覆盖并提示重新刷新编辑。损坏文件会保留并拒绝写入，不会清空为默认值；自动观察会继续提供已确认黑话并说明通用梗库不可用。管理接口只允许控制台身份，会话与争论任务不能编辑。

## 安装与旧版本迁移

运行 `npm run setup:language-support`，然后重启桥接及加载 QQ 预设的 DSH。脚本备份配置，注册 `text.judge`，删除旧的 `text.meme`、`text.tone` 服务及其权限，并将旧 `state/fish-tone.json` 改名存档。视频服务及其他扩展保持现有配置。

没有独立的聊天表达设置文件或控制台面板。旧 `/api/fish-tone` 路由已移除。上游 MIT 许可证与固定修订见 `integrations/vendor/dsh-fish-tone/LICENSE`、`UPSTREAM.md`。
